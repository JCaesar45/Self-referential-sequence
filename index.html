Methodology

No model. No weights. Just counting.

The self-referential sequence implemented here belongs to the Look-and-say family, specifically the "summarize" variant described in the Rosetta Code task. Given a seed, each iteration counts the occurrences of each digit present, then concatenates the count and digit pairs sorted from largest digit to smallest. Digits absent from the previous term are excluded. The sequence terminates when a previously seen term reappears—either as a fixed point or a short cycle [citation:2][citation:8]. This is deterministic computation, not inference. The same seed always produces the same chain, in any language, on any machine.
